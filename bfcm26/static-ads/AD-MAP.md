# BFCM26 Meta static ads: proposed ad map (draft, before design)

Status: this is a proposal for Eli and Katrina to review. Nothing has been designed yet.
The ad brief wasn't pasted into the kickoff, so this map comes from the email master (v10) and the campaign facts.

Main rule: **every concept uses its own layout**. Each one is built around a different graphic idea (ticket, ledger, receipt, timeline, calendar, spec sheet…). All of them stay inside the Cavaier system: white/fog backgrounds, Figtree, Bodoni logo image, black only on buttons, a small red accent, hairlines, real photos.

Formats: 1:1 (1080×1080) and 4:5 (1080×1350) for every concept. 9:16 (1080×1920) for the concepts marked ◆, keeping the top 14% and bottom 20% free of key text.

## Flags
- Matte Cuff (M1) and Glossy + Matte: no photos exist in any source I could read. M1 is blocked until the shoot (or until you approve a Minimal Cuff stand-in, which I'd advise against for an ad).
- Glossy + Matte €66.43 is still pending CEO confirmation, so no concept uses it yet.
- C2 "water-friendly / won't turn you green": the emails use these lines. Confirm they're approved for paid ads (Meta claim review).
- A1 puts the code on a paid ad. Keep it to warm custom audiences only, or drop the code from the image.
- Black-background packshots (bracelet__0, cuban-necklace-1__0, cube-necklace-1__0, role-necklace__0, rope-bracelet-2__0) break the "no big black blocks" rule. Don't use them, or only as small cut-outs.
- The case is a black pouch (jewelry-case__0/1). Fine as a product photo on fog.
